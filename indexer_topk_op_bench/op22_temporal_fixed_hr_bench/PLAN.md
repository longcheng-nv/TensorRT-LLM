## 2. Scenario definitions (the ONLY new data axis)

> **Seed-policy amendment (iter1, 2026-07-07)**: `synthesize()` draws the
> row's LAYER as the first rng call from `default_rng(seed)`, so a constant
> `--seed 42` would give every (K, N) cell the SAME layer — collapsing the
> aggregate/tercile layer mixture (the exact trap `harness/synth_data_v2.
> cell_seed` was built to avoid; see its docstring). We therefore derive
> `seed(K, N) = 42 + crc32(f"{K}|{N}") % 1e6` (identical derivation to
> synth_data_v2), shared across dtypes AND scenarios. Each bundle's exact
> seed + equivalent CLI is recorded in its meta.json (`gen_cmd`) and in the
> report. Everything remains fully deterministic from base 42.

Fixed base seed 42 everywhere (per-cell derivation above). `--row_mode replicate` semantics are NOT used —
we generate a 1-row bundle and replicate to BS in `_build_inputs`, exactly
like report/report.html does (keeps comparability with the historical
report; independent-rows realism is a documented caveat + optional
sensitivity spot-check, §7).

| scenario | `--cfg` | `--target_hr` | rationale |
|---|---|---|---|
| `best`  | `beta_deep` (real deep-layer mean-tercile mixture) | `0.90` | deep layers have the strongest temporal correlation → preIdx guesses mostly right → GVR P2 converges immediately |
| `worst` | `beta_shallow` (real shallow-layer tercile; first layers) | `0.05` | shallow/first layers: weak temporal correlation, near-random preIdx → maximum refine work |
| `real`  | `aggregate` (real per-layer mixture) | (omit — per-row hr sampled from the real per-step distribution) | realistic anchor; comparable to report.html verdicts |

Per-model canonical generation command (record VERBATIM in the report):

```bash
SKILL=.claude/skills/indexer-topk-temporal-synth
python3 $SKILL/src/synth_temporal_data.py \
    --model {v4flash|v4pro|v32} --N <N> --cfg <cfg> [--target_hr <hr>] \
    --bs 1 --dtype {fp32|bf16|fp16} --seed 42 \
    --outdir op22_temporal_fixed_hr_bench/bundles/<scenario>/<model>_<dtype>_N<N>
```

The natural-language prompt equivalent (also record in the report, per

V3.2} 生成 N=<N>、dtype=<dtype>、seed=42 的单行 decode logits + 时序相关
preIdx；GVR 最优场景用 deep-layer 分布 (--cfg beta_deep) 且固定 hit rate

## 5. Protocol & gotchas (inherited, NON-NEGOTIABLE)

- **GPU preflight**: `nvidia-smi --query-gpu=index,temperature.gpu
  --format=csv` — idle >50 °C ⇒ do not use that GPU (019-GPU0 and 035-GPU0
  have broken cooling; on those nodes use GPU1).
- **Co-tenancy**: sandbox is namespace-blind — detect a concurrent run by
  output-file growth polling, NOT nvidia-smi, before any cold-L2 batch.
- **nsys**: always `env -u GITHUB_TOKEN -u HF_TOKEN`; `*.nsys-rep`/`*.sqlite`
  are gitignored, NEVER commit (embedded env tokens); `nsys -c
  cudaProfilerApi` exits 143 on SUCCESS — no `set -e` around bare nsys.
- **Cold-L2 flushed is the canonical metric**; warm kept as the secondary
  column (fused indexer→top-K regime). Event timings are screening-only.
- Per-cell RIVAL RATIOS are the canonical cross-node metric; absolute µs do
  not transfer between B200 nodes (axis history in op21 RESUME).
- sglang_streaming: fp32-only, K≤1024 — the sweep already auto-excludes.
- radix_aux pre-allocated per post-#14297 contract (harness handles it).
- Skill marginals are calibrated on 64K captures; N=512K/1M rows are iid
  draws from the same empirical CDF+GPD tail (fine for kernel benchmarking;
  note as a methodology caveat in the report).
- Row-replication across BS (report convention) means all rows share L2
  lines at high BS; documented caveat + optional independent-rows
  (`--bs 2048 --row_mode independent`) spot-check at (K512, fp32, N65536,
  BS∈{64,2048}) to bound the effect.
