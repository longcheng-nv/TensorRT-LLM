盲提示血统的共同 DNA：把 float 映射为降序有序整数键（负数保位，正数取反补），逐字节（或粗 fp16 bin）建直方图 → 前缀和定位第 K 名所在 bin → 严格更优 bin 直接发射，阈值 bin 内做精选（radix 细化 / 块排序 / tie-select）。SGLang 血统把"阈值 bin 精选"做成显式 tie-buffer + 4 轮 8-bit 精确 radix；其精确性因此以 tie-buffer 容量为条件。 Common DNA of the hint-blind lines: map floats to a descending ordered integer key (negatives keep bits, positives flipped), histogram per byte (or a coarse fp16 bin) → prefix-sum locates the K-th bin → strictly-better bins emit directly, and the threshold bin is refined exactly (radix refinement / block sort / tie-select). The SGLang line turns "threshold-bin refinement" into an explicit tie buffer + a 4-round 8-bit exact radix; its exactness is therefore conditional on tie-buffer capacity.
