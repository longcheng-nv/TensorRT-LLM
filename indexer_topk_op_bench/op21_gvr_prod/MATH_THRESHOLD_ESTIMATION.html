重新定位 secant 问题 · op21 GVR-MS 战役 · 2026-07-07 · B200/B300,DSv3.2/DSv4 decode indexer
TL;DR. Once the problem is formalized, the answer collapses cleanly: the optimal threshold is a plug-in order statistic of the gathered sample, and the only genuinely unknown quantity is the one-dimensional effective retention rate h. Because h is scale-free and temporally stationary — unlike the threshold itself — the best efficient solution is not a better root-finder (secant) but a sequential estimator of h in rank space across decode steps. The GVR-MS fast path already sits at the information-theoretic one-pass lower bound; all remaining mathematical slack lives in estimating h (buys tail robustness) and in a smarter fallback (regula falsi on already-measured CDF points instead of blind bisection). None of this raises the mainline geomean materially — it removes the preIdx-driven variance cliffs quantified by op22.
要点。问题一经形式化,答案会收敛得非常干净:最优阈值本质上是 gather 样本的一个 plug-in 次序统计量,唯一真正未知的量是一维的有效保留率 h。由于 h 是标度不变、跨步平稳的 —— 而阈值本身不是 —— 最佳高效解不是更好的求根器(secant),而是在秩空间对 h 做跨 decode step 的序贯估计。GVR-MS 快路径已经达到信息论意义上的单遍下界;剩余的全部数学余量在于估计 h(收益是尾部鲁棒性),以及更聪明的 fallback(在已测 CDF 点上做 regula falsi,替代盲二分)。 这些都不会显著抬高主线 geomean —— 它们消除的是 op22 定量证实的 preIdx 驱动的性能方差悬崖。

1Formalization问题的形式化

Let the current decode step's logits row be x1, …, xN. The target is the K-th largest value vK — the ideal threshold. The observation is the gathered sample

S = { xj : j ∈ preIdx },  |S| = K

where preIdx is the previous step's top-K index set. The cost model (measured): one full-row count_ge(θ) pass costs one cold sweep (~22 µs at N=1M — the entire radix kernel's budget); any O(K) computation on S in shared memory is effectively free. Exactness never depends on the threshold — downstream counts plus the exact band refine are the authority — so the threshold only needs to bracket K with high probability in one shot.

The sample is not i.i.d. It is a temporally coherent sample biased toward the upper tail: of the global top-r values, approximately H(r) appear in S, where H is the rank-conditional retention curve with average slope h (the hit rate; measured Pro 0.69–0.77, Flash 0.36–0.46). The (1−h)K "miss" entries have current values that sink below vK and concentrate near the selection boundary (real-capture measurement; op22 mechanism study).

设当前 decode step 的 logits 行为 x1, …, xN,目标是第 K 大值 vK(理想阈值)。观测为 gather 样本

S = { xj : j ∈ preIdx },  |S| = K

其中 preIdx 是上一步的 top-K 下标集。代价模型(实测):全行一次 count_ge(θ) = 1 遍冷 pass(N=1M 时 ~22 µs,恰好等于 radix 整个内核的预算);对 S 的任何 O(K) smem 运算 ≈ 免费。精确性从不依赖阈值 —— 下游 count + 精确 band refine 才是 authority —— 所以阈值只需高概率一步夹住 K。

样本不是 i.i.d. 的。它是偏向上尾的时间相干抽样:全局前 r 名中约 H(r) 个出现在 S 里,H 为秩条件保留曲线,平均斜率 h(命中率;实测 Pro 0.69–0.77、Flash 0.36–0.46)。未保留的 (1−h)K 个 "miss" 条目,其当前值沉到 vK 之下且聚在选择边界附近(real capture 实测;op22 机制研究)。

2The key reduction: the problem is one-dimensional关键化简:问题是一维的

Let GS−1(m) denote the m-th largest value of S. The sample's m-th order statistic corresponds to global rank ≈ H−1(m), so the estimator that makes the full-row count land at K is the plug-in quantile

θ̂ = GS−1( H(K) ) ≈ GS−1( h·K )

All value-space information is already contained in the sample's order statistics (they are the sufficient nonparametric summary). The only unknown is the scalar h. This reduction has three immediate consequences:

  • P1b's histogram + rank-quantile placement is already the correct skeleton of this estimator.
  • The static qfracs (0.25, 0.5, 0.75) are a grid search over the unknown h, batched into a single pass — the M-threshold ladder is a vectorized bracket, not an approximation artifact.
  • Both measured performance cliffs are literally "h fell outside the static bracket": h > 0.75 collapses the sandwich pair to columns (0,1), which the fused collect cannot serve → fallback (op22's refine cliff, 40 µs ↔ 240 µs at N=1M); rows with h < 0.25 trigger the all_ge miss mode (iter0.5: 5.5% of rows); the K512 slot overflow is the same phenomenon at the collect column (cand ≈ 0.75K/h ≫ capacity when h is low → 124 µs ↔ 187 µs).

记 GS−1(m) 为 S 的第 m 大值。样本第 m 名对应全局第 ≈ H−1(m) 名,于是使全行 count 落在 K 的估计器就是 plug-in 分位数

θ̂ = GS−1( H(K) ) ≈ GS−1( h·K )

值空间的全部信息都已包含在样本次序统计量里(它们是非参数意义下的充分统计量)。唯一未知的是标量 h。这一化简有三个直接推论:

  • P1b 的直方图 + 秩分位放置已经是这个估计器的正确骨架。
  • 静态 qfracs (0.25, 0.5, 0.75) 本质是对未知 h 的一次网格搜索,批处理在同一遍 pass 里 —— 多阈值 ladder 是向量化的夹逼,不是近似的权宜之计。
  • 两个已实测的性能悬崖恰好都是"h 落在静态括号之外":h > 0.75 时 sandwich 对塌到 (0,1) 列, fused collect 服务不了 → fallback(op22 的 refine 悬崖,N=1M 处 40 µs ↔ 240 µs);h < 0.25 的行触发 all_ge miss 模式(iter0.5:5.5% 的行);K512 slot 溢出是同一现象在 collect 列上的表现 (h 低时 cand ≈ 0.75K/h ≫ 容量 → 124 µs ↔ 187 µs)。

3Information-theoretic lower bound: the fast path is already at it信息论下界:快路径已经打到界上

Any exact top-K algorithm must read every element at least once — an adversary can hide a top-K member at any unread position — so ≥ 1 full pass is a hard lower bound. The GVR-MS fast path is exactly one full pass (fused M=4 ladder + speculative collect) plus O(K) side work plus an O(band) refine whose cost is barrier-floor-bound. It is therefore pass-optimal. The optimization space that remains has exactly two degrees of freedom:

  1. Maximize the probability that one pass suffices (straddle within columns 1..M−1, no slot overflow) — purely an estimation-quality problem.
  2. Minimize the price of failure — a fallback-design problem.

Any scheme that adds an unconditional second pass to the fast path — including 1–2 unconditional secant iterations — moves away from the bound. This is the single mathematical statement that unifies the falsification record: op18's L2-trap (an extra round rides a cold pass, ~22K cyc vs ~5K warm), op16's threshold-pinning tax (P2 ×1.3–2.5), op12's opt-2 rejection, and the warm-start secant regressions (0.958–0.973×).

任何精确 top-K 算法都必须至少读全行一遍 —— 对手可以把一个 top-K 成员藏在任何未读位置 —— 所以 ≥ 1 遍全行是硬下界。GVR-MS 快路径恰好是 1 遍(fused M=4 ladder + 投机 collect)+ O(K) 侧工作 + O(band) refine(其成本是 barrier 地板)。因此它已是 pass 最优。剩余的优化空间只有两个自由度:

  1. 最大化一遍即成功的概率(straddle 落在列 1..M−1 内、collect 不溢出)—— 纯估计质量问题。
  2. 最小化失败时的代价 —— fallback 设计问题。

任何往快路径上加无条件第 2 遍的方案 —— 包括无条件的 1–2 步 secant 迭代 —— 都是在离开下界。 这一条数学陈述统一解释了全部证伪记录:op18 的 L2 陷阱(额外一轮骑在冷 pass 上,~22K cyc 对比 ~5K 热)、 op16 的钉阈值税(P2 ×1.3–2.5)、op12 opt-2 的否决、以及 warm-start secant 的回退(0.958–0.973×)。

(a) Cross-step recursion on ĥ

At the end of each step, the realized h is readable at ~zero cost: the sandwich already knows M0, or a single predicated popcount over the smem stash gives |S ∩ {v ≥ θfinal}| / K — an O(K) shared-memory operation. Update ĥt+1 with an EMA / first-order Kalman filter; cold-start falls back to the static bracket. Engineering cost: one persistent scalar per row, plumbed alongside preIdx (a side tensor).

(b) The ladder counts are a free within-step observation

After the single pass, the four exact points (θm, cm) are true samples of the global CDF; ĥ = fm·K / cm at the bracketing columns is a direct per-step measurement of h, fed back into (a) at zero extra passes.

(c) h-aware placement is an optimal-experimental-design problem

Columns should not be spread uniformly but placed geometrically around ĥ (e.g. f ∈ ĥ·{0.8, 1.0, 1.25} plus the gmin anchor), with width set by the AR(1) innovation std of ht so that P(straddle within columns 1..3) ≥ target. The collect column becomes h-aware the same way: choose fc such that fc·K/ĥ ≤ slot capacity — this single constraint eliminates the K512 overflow cliff. Expected band shrinks from 0.25·K/h (measured ~900 at K1024 — the formula matches) toward the intrinsic noise floor of any K-sample estimator, the binomial order-statistic fluctuation O(√(h(1−h)K))/h ≈ tens-to-hundreds of ranks. (See §6 for why band shrinkage itself is worth little.)

(d) The misses are not noise — they are free boundary-density samples

This is the most elegant structural feature of the problem: the (1−h)K miss values concentrate just below vK, so their empirical distribution is precisely an estimate of the local density N·f(vK) — the slope a secant step needs — sampled exactly where it is needed. The current histogram physically contains them (the stash is histogrammed in full), but static qfracs do not exploit this structure.

(a) 对 ĥ 的跨步递归

(d) miss 值不是噪声 —— 是免费的边界密度样本

这是本问题最优雅的结构:(1−h)K 个 miss 的当前值恰好聚在 vK 下方,其经验分布正是局部密度 N·f(vK) 的估计 —— 即 secant 需要的斜率 —— 而且采样位置天然集中在最需要的地方。当前直方图物理上包含了它们 (stash 全量进直方图),但静态 qfracs 没有利用这个结构。

5Secant's proper place: two roles, neither costs an extra passsecant 的正确位置:两处,都不花额外 pass

Root-finding on the monotone step function g(θ) = count_ge(θ) − K, where one evaluation costs one full-row pass, is an "expensive black box + free surrogate" problem. The optimal strategy: do all interpolation on the free surrogate (the sample CDF composed with the h-mapping) and spend expensive evaluations only to verify/bracket.

  • Fast path — secant is already there, implicitly. The ladder is a vectorized one-step secant: its four evaluation points are chosen by the surrogate and executed in a single pass. Once the counts return, no further evaluation is needed to locate vK inside the band: P4's exact rank-scatter performs that selection, and its cost is barrier-bound (~7 barriers), not band-size-bound. There is no seat for an explicit secant on the fast path — not because secant is bad, but because its work is already absorbed by free interpolation plus P4.
  • Fallback — the one place an explicit secant belongs. The current miss path runs geometric expansion (≤12 steps) + blind bisection (≤30 steps), each step one full-row pass; in the cluster kernel each pass is additionally amplified by the leader-only single-CTA recount (~95 µs/pass at N=1M). Blind bisection discards the four exact CDF points already in hand and the entire sample density shape. The correct update is regula falsi: interpolate within the measured bracket (θm, cm) using the sample histogram as the monotone interpolant, landing in [K, kC] in an expected 1–2 passes instead of 2–4+. This is exactly the user's secant idea — placed where it only pays when the row was going to pay anyway.

对单调阶梯函数 g(θ) = count_ge(θ) − K 求根、且每次评估 = 1 遍全行,属于 "昂贵黑盒 + 免费代理模型"的求根问题。最优策略:所有插值都在免费代理上做(样本 CDF 复合 h 映射), 昂贵评估只用于验证/夹逼。

  • 快路径 —— secant 已经隐式存在。ladder 本身就是向量化的一步 secant:4 个评估点由代理模型 选出、在同一遍 pass 内完成。counts 回来之后,band 内定位 vK 不再需要任何评估: P4 的精确 rank-scatter 就在做这个选择,且其成本是 barrier 地板(~7 个 barrier)而非 band 大小。快路径上没有 显式 secant 的位置 —— 不是 secant 不好,而是它的工作已被免费插值 + P4 吸收。
  • fallback —— 显式 secant 唯一该在的地方。当前 miss 路径是几何扩张(≤12 步)+ 盲二分(≤30 步), 每步 1 遍全行;cluster 内核里每遍还被 leader 单 CTA 重数放大(N=1M 处 ~95 µs/遍)。盲二分丢弃了手上已有的 4 个精确 CDF 点和整个样本密度形状。正确的更新是 regula falsi:在已测夹逼区间 (θm, cm) 内以样本直方图为单调插值函数,期望 1–2 遍落进 [K, kC] (对比现在 2–4+ 遍)。这正是"secant 思想"—— 但放在只有本来就要付费的行才付费的位置。

6Honest bounds on the gains (against the measured record)收益的诚实定界(对照实测记录)

  • Band shrinkage is worth almost nothing on the fast path. P4 is barrier-floor-bound (op12: ~7–14 barriers; only ~15% count-reducible, 7050→5959 cyc for cand 2K→1K), and at large N P4 is just 11–15% of the MS kernel (2.3–4.0 µs of ~25–27 µs). Exclude this from the expected payoff of §4(c).
  • The real payoff is entirely in the tail. Straddle probability rises (all_ge 5.5% → ≈0); the pair-(0,1) fallback cliff (op22: 40 µs ↔ 240 µs) and the K512 slot-overflow cliff (124 µs ↔ 187 µs) get pushed multiple σ out; the fallback itself drops from blind bisection to 1–2 interpolated passes. Net effect: the "op21 worst case ~2× slower than plain cutedsl" robustness gap named by op22 is closed, and the variance of performance with respect to preIdx quality collapses — which was the original concern motivating this analysis.
  • The mainline geomean barely moves. On real data in the production N range, the median P2 iteration count is already 1, straddle is already 94.5%, and the fast path is at the pass lower bound.
  • band 收缩对快路径几乎不值钱。P4 是 barrier 地板(op12:~7–14 个 barrier;候选数只有 ~15% 可缩减性,cand 2K→1K 时 7050→5959 cyc),且 largeN 时 P4 只占 MS 内核的 11–15%(~25–27 µs 中的 2.3–4.0 µs)。 §4(c) 的期望收益中要剔除这一项。
  • 真正的收益全在尾部。straddle 概率上升(all_ge 5.5% → ≈0);pair-(0,1) fallback 悬崖 (op22:40 µs ↔ 240 µs)与 K512 slot 溢出悬崖(124 µs ↔ 187 µs)被推到多个 σ 之外;fallback 本身从盲二分变为 1–2 遍插值。净效果:op22 点名的 "op21 worst case ~2× slower than plain cutedsl" 鲁棒性缺口被抹平, 性能对 preIdx 质量的方差大幅收窄 —— 而这正是引发本次分析的原始问题意识。
  • 主线 geomean 几乎不动。real 数据、生产 N 段上,P2 迭代中位数已是 1,straddle 已 94.5%, 快路径已在 pass 下界上。

7One-sentence answer一句话总结

Given preIdx and its gathered values, the best efficient estimator of "the threshold whose count ≈ K" is the plug-in sample-quantile GS−1(ĥ·K), with ĥ tracked sequentially across decode steps by an EMA/Kalman filter in rank space and corrected for free by each step's ladder counts; the multi-threshold ladder is the optimal single-pass experimental design under h-uncertainty; and explicit secant survives only in the fallback, as regula falsi with the sample density as its slope. GVR-MS already implements the h-agnostic version of this solution and sits at the one-pass lower bound; all remaining mathematical headroom lies in sequentializing ĥ — a direction never yet tried, fundamentally distinct from the falsified value-space warm-start — and its payoff shape is collapsing tail variance, not raising the mean.

8Calibrating the premise, and the unified cost model校准前提,与统一代价模型

Decompose one secant iteration into its two components:

  • The O(N) streaming body: v = load; cnt += (v ≥ θ) — predicated compare + register accumulation, with zero shared memory, atomics, divergence, or sync in the hot loop, and perfectly coalesced loads. This is indeed the friendliest primitive on the architecture; the premise holds exactly here.
  • The O(1) sync epilogue: warp reduce + 1–2 block barriers + a tid0 decision — nanosecond-scale on a single CTA, negligible.

Two corrections then reshape the design space:

  1. The ladder inherits secant's streaming body wholesale. An M-threshold ladder's hot loop is the same predicated compare + register accumulate (op21's fused collect is per-thread slots — also atomic-free). It introduces no new synchronization; what it introduces is a compare/accumulator width tax τ(M), measured on cold passes by op18: τ(1)=τ(2)=1.0, τ(4)=1.46, τ(8)=2.7. So "secant vs. ladder" is not sync-free vs. sync-heavy — it is a rounds × width resource-allocation problem.
  2. Sync cost is regime-dependent, and clusters invert the conclusion. On a single CTA an extra secant round costs ≈0 in sync. But hugeN rows must be row-chunked across C CTAs, where every iteration needs a DSMEM count merge + cluster barrier (measured ~0.3–0.5 µs each; iter3/4: every "distribute the fixed part" move lost to cluster-barrier cost; today's msc fallback degenerates further to a leader-only single-CTA full-row recount, ~95 µs/pass at N=1M). Exactly where secant's "one more round" looks cheapest, the cluster architecture taxes it hardest.

9Sequential design: three structure theorems, and the optimal form of secant序贯设计:三条结构定理,与 secant 的最优形态

Work in rank space (invariant under monotone transforms of logits). Define the target sample rank ρ* = H(K) ≈ h·K — "the equivalent rank of vK inside the sample" — with prior π(ρ): wide (the marginal h distribution over rows/layers/models, support [0.08, 0.95], strongly layer-dependent) without tracking; a tight AR(1) posterior (innovation σ dominating the √(h(1−h)K) order-statistic floor, ~±15 ranks at K=1024) with the Part-I sequential ĥ. Each round: choose M evaluation points at sample-rank fractions f1<…<fM (thresholds θm = GS−1(fmK)), pay Tpass, receive exact counts — the posterior collapses onto the adjacent interval containing K. This is Bayesian sequential experimental design with batched evaluations, and its optimal policy has clean structure:

Theorem 1 (regime split — the optimal M×R). Compare the marginal cost of "one more round" vs. "more width". Regime W: a second round costs γ2P ≈ 0.2P while widening M 2→4 costs 0.46P riding the cold first pass; 0.2 < 0.46 ⇒ narrow width + sequential refine is optimal (M*=2–3, warm secant on miss). Regime C (single-CTA hugeN or cluster): a second round costs a full P + s(C), dwarfing any width tax ⇒ one-shot is optimal: R*=1, with M* = argminM τ(M)P + (1−cov(M))·Cmiss — M*=4 at current miss prices. This theorem retro-dicts two independently measured optima: op18's dispatch ("M2R2 at ≥131K — M2 is the only tax-free width on a cold pass; R2's warm refine is the safety net"; "M4-collapse-everything" forbidden) and op21-msc's hard constraint (R_rounds==1 AND fuse_collect required for cluster). The theory unifies two locally discovered optima as the two corners of one cost model.

Theorem 2 (placement = prior-quantile quantization). Given M, the placement maximizing one-shot success puts f1..fM−1 at quantiles of π(h), plus the gmin anchor which guarantees the count ≥ K side:

Pr(miss) = π(h ≤ fmin) + π(h > fmax)

Static (0.25, 0.5, 0.75) is the wide-prior solution — hence Flash's low-h tail yields 5.5% all_ge and h > 0.75 (Pro's upper edge / the op22 stress construction) yields the pair-(0,1) cliff: the two observed failure classes are the inevitable tax of a wide prior. On Pro real multi-turn data the cliff is not a tail tax but the majority-step regime: 74% / 62% of decode steps (turn 1 / turn 2, worst layer 100%) sit in the h > 0.75 pair-(0,1) zone under the static columns. With tracked ĥ the prior tightens; the same M=4 columns move to ĥ·{1−2σ, 1, 1+2σ} and the measured miss drops to 13.4% / 16.4% (≈5× — direction confirmed; the residual is the §10 process-variance floor, not a multi-σ event). The collect-column constraint fc·K/ĥlo ≤ cap is solved by the same formula — the K512 overflow cliff disappears inside it.

Theorem 3 (the evaluation target is an interior point, not K). The acceptance interval [K, kC] is wide (kC/K = 10 / 5 / 2.5–3). Undershoot (count < K) pays an upward extra round; overshoot beyond kC pays the overflow fallback. The optimal aim point is m* = K·(kC/K)α with α set by the ratio of the two failure prices (α ≈ 0.3–0.5). The legacy secant kernel's kFTarget ≈ 1.5–2×K (3072/4096 for K2048) is precisely the empirical form of this solution — another retro-validation.

The optimal form of secant: bridge regula falsi (nonparametric, reuses all measured information)

After a miss (or inside the fallback), classical secant interpolates linearly in value space — an implicit local-linearity assumption on the CDF, which is exactly what blows up at density spikes (the op13 linear-eval finding). But a strictly better interpolant is in hand: the sample CCDF affinely calibrated inside the measured bracket. Given measured (θa, ca), (θb, cb) bracketing the target (ca ≥ m* > cb), define

ĉ(θ) = cb + (ca − cb) · ( GS(θ) − GS(θb) ) / ( GS(θa) − GS(θb) ),    θnext = ĉ−1(m*)

— shape from the sample (free; an O(K) smem lookup straight off the P1b histogram), level and slope pinned by two exact measured points. Three mathematical properties:

  1. Endpoint-exact and monotone — cannot leave the bracket (regula-falsi stability built in, stronger than raw secant).
  2. Its slope comes from the miss density: when the bracket sits near the selection boundary, the sample values inside it are dominated by the (1−h)K misses — Part I §4(d)'s "free boundary density" formally enters the update rule. This is the substantive union of preIdx and secant.
  3. Expected one-step landing: the landing-rank error is O(√(#samples in bracket))/h ≈ tens of ranks, while the acceptance width kC−K is hundreds to thousands ⇒ Pr(land in [K, kC] in one step) → 1. Blind bisection needs log2(bracket/acceptance) ≈ 2–4+ steps, each a full-price pass (C×-amplified in msc today).

定理 1(regime 分裂 —— 最优的 M×R 组合)。比较"加一轮"与"加宽度"的边际成本。 Regime W:第二轮成本 γ2P ≈ 0.2P,而 M 从 2 加宽到 4 的成本 = 0.46P(骑在冷首轮上); 0.2 < 0.46 ⇒ 窄宽度 + 序贯 refine 最优(M*=2–3,失手后温遍 secant)。Regime C (单 CTA hugeN 或 cluster):第二轮成本 = 全价 P + s(C),远超任何宽度税 ⇒ 一轮定胜负最优:R*=1,M* = argminM τ(M)P + (1−cov(M))·Cmiss —— 按当前 miss 价格,M*=4。这条定理回验了两个独立实测出的最优:op18 的 dispatch 表("≥131K 用 M2R2 —— M2 是冷遍上唯一免税宽度,R2 的温 refine 是安全网";禁 "M4-collapse-everything")和 op21-msc 的硬约束(cluster 要求 R_rounds==1 AND fuse_collect)。理论把两个各自摸出的局部最优统一为同一 代价模型的两个角点。

定理 2(放置 = 先验分位数量化)。给定 M,使一轮成功概率最大的放置是把 f1..fM−1 放在 π(h) 的分位点上,外加 gmin 锚点保证 count ≥ K 一侧永不缺失:

Why class A is the whole point. The static layer is provably model-sensitive today: one and the same qfracs (0.25, 0.5, 0.75) produces the 5.5% all_ge miss mode on Flash (low h, measured 0.36–0.46) and the pair-(0,1) fallback cliff on Pro (high h, 0.69–0.77) — two models, two opposite failure modes from a single parameter set. That is the wide-prior tax of Theorem 2, and it is exactly what ĥ-adaptive placement removes. A model switch is therefore the scenario where HLS's advantage over the static kernel is largest, not a re-tuning liability. Why class C does not move with the model: M*, α, the regime split and the N-gates are functions of pass-cost ratios and sync prices only; the campaign record shows these ratios are hardware-invariant across B200↔B300 (op17 full-grid 720/720 pick invariance; op21/op23 ratio invariance) and contain no distributional quantity. Class B degrades gracefully: an under-tuned gain merely inflates σ̂, which the ±2σ̂ placement absorbs as extra width; a cold-start prior that misses the new model's h range only slows the first few steps of each row before the observations wash it out.

Boundary conditions — three distribution shifts that adaptation cannot absorb. (i) Temporal-coherence collapse (lag-1 ρ of ht low: a redesigned indexer, no preIdx reuse): what breaks is GVR's premise, not an HLS constant — the correct response is dispatch-level defense (fall back to radix), never parameter search; this is the op22 stress-scenario verdict. (ii) Non-stationary / regime-switching ht — no longer a hypothetical: measured on Pro real multi-turn captures. The 30-layer mean h series shows V-shaped collapses every ~15–18 steps, depth 0.4–0.7, with 24–30/30 layers moving in sync (content/query-driven jump-diffusion, not Gaussian AR(1); max single-step |Δh| = 0.68). The originally proposed defense — robust innovation gating that reverts to the static wide prior — is measured ineffective (13.6% vs 13.4% miss): the spikes are genuine all-layer state jumps, not observation outliers, and a ±2σ̂ Gaussian band systematically misses them. What bounds the loss instead: consecutive-miss runs are ≤ 5–7 steps (contamination is bounded) and each miss costs only the cheap shipped fallback pass — the loss stays bounded, but through fallback price, not through online detection. (iii) MTP (next_n > 1): cross-row h-correlation is an unverified assumption (§10) and must be measured per model that enables it — a validation obligation, not a knob.
Model-switch playbook. ① Fill the class-D row (K, cr; new K ⇒ one small kC capacity bench). ② Run the class-B validation set once: lag-1 ρ and marginal of ht on a real capture — the capture must include a multi-turn agentic trace (§10 obligation iv) — plus the MTP cross-row correlation if applicable. ③ Tune nothing. If step ② fails its gates, the answer is dispatch defense, not parameter search.
