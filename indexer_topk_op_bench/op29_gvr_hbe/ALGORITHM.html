一句话:把 SGLang v2 的"直方图遍 + 收集遍"两遍全行 DRAM 扫描压缩成一遍: 先用 4096 个采样点放置一条候选目标收集列(阈值下界猜测),单遍扫描时每元素只做 1 次比较收集候选; 收集后用计数判据(候选数 ≥ K)证明 top-K 已被包含,再从仅候选的迷你直方图恢复精确阈值 bin, 用原有 tie 机制边界精确求解。猜错则整行回退原两遍算法(fail-soft,精确性与命中率无关)。 同批实测:引擎化域(N≥65536、BS≥1024)对 sglang_v2 1.03–1.75×,全网格 906 cell 无一输超 5%。

One-liner: compresses SGLang v2's two full-row DRAM passes (histogram pass + collect pass) into one: a 4096-point row sample places a candidate-targeted collect column (a guessed lower bound on the threshold), so the single pass does 1 comparison per element; a count-validity check (candidates ≥ K) then proves top-K containment, the exact threshold bin is recovered from a candidates-only mini-histogram, and the stock boundary-exact tie machinery resolves the output. A wrong guess falls back to the stock 2-pass for that row (fail-soft; exactness never depends on the guess). Same-batch measured: engaged domain (N≥65536, BS≥1024) 1.03–1.75× over sglang_v2; zero of 906 grid cells lose >5%.

1. 问题与基线1. Problem & baseline

场景:DeepSeek-V4 稀疏注意力 indexer 的 decode 阶段 top-K —— 每行从 N 个 fp32 logits 中选出 K 个最大值的索引(K=512/1024/2048 对应 V4-Flash / V4-Pro / V3.2),N 至 262K(部署主战场), BS 至 2048。精确性判据为 tie-aware 值多重集:输出索引对应的值排序后与 torch.topk 完全一致(平局元素可互换,数量必须精确为 K)。

Setting: decode-phase top-K for the DeepSeek-V4 sparse-attention indexer — per row, select the indices of the K largest of N fp32 logits (K=512/1024/2048 for V4-Flash / V4-Pro / V3.2), N up to 262K (the deployment envelope), BS up to 2048. The exactness criterion is the tie-aware value multiset: sorted values at the output indices must equal torch.topk's exactly (tied elements interchangeable, cardinality exactly K).

基线/对手 sglang_v2(sglang@main 的 DSv4 top-K,2026-07 树内外全场最快)对流式行固定两遍: ① 全行直方图遍 —— 每元素做 fp16-ordered 变换 + smem 原子加,得 4096-bin 直方图,求出阈值 bin b*; ② 全行收集遍 —— 每元素 2 次比较,>b* 直接输出,=b* 进 tie 缓冲精确选边界。 两遍 = 2×N×4B 的 DRAM 读,它已坐在"无先验信息"的信息下限上。

The baseline/rival sglang_v2 (sglang@main's DSv4 top-K, fastest in- or out-of-tree as of 2026-07) does a fixed two passes on streaming rows: ① a full-row histogram pass — per element an fp16-ordered transform + smem atomic into a 4096-bin histogram, yielding the threshold bin b*; ② a full-row collect pass — 2 comparisons per element, >b* emitted directly, =b* into a tie buffer for boundary-exact selection. Two passes = 2×N×4B of DRAM reads; it sits at the prior-free information floor.

核心洞见:阈值 bin 只需要"猜得不高于 b*"(单侧安全)。一个便宜的行采样就能给出 这样的下界猜测,而猜测的对错可以在单遍扫描后用一个计数零成本判定 —— 于是第二遍在命中时完全消失。

Core insight: the threshold bin only needs to be guessed at or below b* (one-sided safety). A cheap row sample provides such a lower bound, and whether the guess worked is decidable after the single pass by one count, at zero cost — so the second pass vanishes entirely on a hit.

2. 分发结构2. Dispatch structure

gvr29 是 sglang_v2 的逐字 fork(register / streaming / 8-CTA cluster 三路不动), 仅新增第 4 层:N ≥ 65536 的流式行走 HBE(iter12 守卫;2 条 shape-keyed 规则)。守卫外与 sglang_v2 按构造等价 —— 零回归由结构保证。

gvr29 is a verbatim fork of sglang_v2 (register / streaming / 8-CTA-cluster paths untouched) plus one new tier: streaming rows with N ≥ 65536 take HBE (iter12 guard; 2 shape-keyed rules). Outside the guard the op equals sglang_v2 by construction — zero regression is structural.

4. 伪码4. Pseudocode

每行一个 CTA(1024 线程),与 kernel 实现一一对应 (src/gvr29/sgl_kernel/deepseek_v4/topk_hbe.cuh)。bin(x) = fp16 转换后按符号翻转的 16 位有序键右移 4 位(4096 bin,对 fp32 单调)。

One CTA (1024 threads) per row; maps 1:1 onto the kernel (src/gvr29/sgl_kernel/deepseek_v4/topk_hbe.cuh). bin(x) = the sign-flipped 16-bit ordered key of the fp16 cast, shifted right by 4 (4096 bins, monotonic in the fp32 value).

// ---- Phase H0: sample & place the collect column (per row) ----
hist[4096] ← 0
for t in 0..4095 parallel:                // 64 chunks × 64 contiguous elems
    c, o ← t / 64, t mod 64                    // chunked ⇒ coalesced 256B runs
    idx  ← min(c · max(64, N/64) + o, N−1)
    atomicAdd(hist[bin(x[idx])], 1)
rS_K ← max(1, 4096·K / N)                      // rank K in sample space
binA ← find_threshold(hist, rank = 2·rS_K)    // cand target ≈ 2K ⇒ one-sided margin
vA   ← coarse_bin_lower_bound(binA)           // exact fp32 bin edge
hist ← 0                                       // smem histogram reused in H2

// ---- Phase H1: the ONE fused DRAM pass (1 cmp/elem) ----
cnt_a ← 0
for (val, idx) in row parallel:              // float4-vectorized stream
    if val ≥ vA:
        p ← atomicAdd(cnt_a, 1)
        if   p < capA:          bufA[p] ← {val, idx}          // smem (capA = 4K|2K·8B)
        elif p < capA + spillA:  spillA_g[p − capA] ← {val, idx} // global overflow (28·K)
        // beyond spillA ⇒ counted but dropped ⇒ H2a will reject ⇒ fallback

// ---- Phase H2: count-validity, exact b*, boundary-exact resolve ----
if K ≤ cnt_a ≤ capA + spillA:                  // top-K provably ⊆ candidates (§5)
    for e in candidates parallel: atomicAdd(hist[bin(e.val)], 1)
    b* ← find_threshold(hist, rank = K)         // GLOBAL threshold bin — exact (§5)
    v_hi, v_lo ← bin edges of b*
    for e in candidates parallel:
        if   e.val ≥ v_hi: out[atomicAdd(count_gt,1)] ← e.idx   // strictly above b*
        elif e.val ≥ v_lo: tie_buf[atomicAdd(count_eq,1)] ← e   // boundary bin
    handle_tie(tie_buf, K − count_gt)          // stock machinery, unchanged
else:                                          // MISS — sample noise or blowout
    TopKStreaming::forward(row)                // stock hist pass + collect pass

// ---- Host dispatch (gvr29_standalone.cu; guard = iter12) ----
if use_hbe and not cluster_eligible and max_seq_len ≥ 65536:
    launch gvr29_hbe_kernel<PDL, kColB=false>   // dyn smem = capA·8B only
else: // verbatim sglang_v2 dispatch: register / streaming / 8-CTA cluster
    stock_dispatch(...)

5. 正确性论证5. Correctness argument

  • 单侧安全:binA 只需 ≤ b*。若 cnt_a ≥ K,则 vA 之上至少有 K 个元素, 即第 K 大值 ≥ vA,故 b* ≥ binA —— 计数本身就是判据,无需知道 b*。

    One-sided safety: binA only needs to be ≤ b*. If cnt_a ≥ K, at least K elements lie at/above vA, so the K-th largest value is ≥ vA and hence b* ≥ binA — the count itself is the certificate; b* need not be known.

  • 候选集完备:cnt_a ≤ capA+spillA 保证没有候选被丢弃;候选集 = 全部 val ≥ vA 的元素 ⊇ 全部 val ≥ v(b*) 的元素 ⊇ top-K。

    Candidate completeness: cnt_a ≤ capA+spillA guarantees no candidate was dropped; the candidate set = all elements ≥ vA ⊇ all elements ≥ v(b*) ⊇ the top-K.

  • 迷你直方图给出全局 b*:所有落在 bin ≥ binA 的元素都是候选,故候选直方图在 [binA, 4095] 区间与全行直方图逐 bin 相等;find_threshold(K) 的解落在该区间内(由上一条), 因此等于全局解。

    The mini-histogram yields the global b*: every element in bins ≥ binA is a candidate, so the candidate histogram equals the full-row histogram bin-for-bin on [binA, 4095]; find_threshold(K)'s solution lies in that interval (previous bullet), hence equals the global one.

  • 边界精确:b* bin 内的平局用与 stock 完全相同的 tie 机制精确选取 K − count_gt 个 —— 输出满足 tie-aware 值多重集判据。

    Boundary exactness: ties inside bin b* are resolved by the identical stock tie machinery selecting exactly K − count_gt — the output meets the tie-aware value-multiset criterion.

  • fail-soft:判据不通过(采样噪声或溢出)则整行执行原两遍算法。 采样质量只影响速度,从不影响精确性。Gate:324/324(3 场景 × 3 K × 4 N × 3 BS × 双 colB 臂,含全域强制引擎化与对抗 hint),见 gate_op29.log。

    Fail-soft: if the check fails (sample noise or blowout) the row runs the stock 2-pass. Sample quality moves only speed, never exactness. Gate: 324/324 (3 scenarios × 3 K × 4 N × 3 BS × both colB arms, incl. forced engagement everywhere and adversarial hints), see gate_op29.log.
